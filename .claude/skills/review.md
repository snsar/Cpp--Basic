Review user-submitted C++ code for an exercise.

## Usage
/review <code hoặc paste code>

## Behavior
1. Check if the code compiles cleanly with `g++ -std=c++17 -Wall`.
2. Verify correctness against the exercise's example input/output.
3. Give feedback in Vietnamese on:
   - Logic errors or edge cases missed
   - Code style and readability
   - Performance improvements (if any)
4. Suggest an improved version if needed.
